🔌 API 엔드포인트

메서드 엔드포인트 설명
GET /api/health 서버 상태 확인
GET /api/users 사용자 목록 조회
POST /api/users 사용자 생성
GET /api/users/<id> 특정 사용자 조회
PUT /api/users/<id> 사용자 수정
DELETE /api/users/<id> 사용자 삭제

🚀 실행 방법

$ cd backend
$ python -m venv venv
$ venv\Scripts\activate
$ pip install -r requirements.txt
$ python run.py
➜ http://127.0.0.1:5000
